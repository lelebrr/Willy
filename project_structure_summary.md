# Estrutura do Projeto Willy

Este projeto é um firmware unificado para ESP32-S3 com foco em pesquisa de segurança.

## Pastas Principais

- `src/` - Código fonte (core, modules, ui, web_files)
- `include/` - Headers compartilhados
- `lib/` - Bibliotecas
- `scripts/` - Scripts de build
- `boards/` - Definições de boards
- `docs/` - Documentação
- `sd_files/` - Arquivos para SD card
- `pcbs/` - Projetos de PCB
- `media/` - Recursos de mídia
- `embedded_resources/` - Recursos embarcados
